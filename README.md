# MPC — релізи

Тут лежать лише готові збірки розширення Chrome **More Position Checker (MPC)** для колег.
Вихідного коду тут немає.

## ⬇️ [Завантажити MPC (остання версія)](https://github.com/acidhacker/mpc-releases/releases/latest/download/mpc.zip)

> ⚠️ Не натискайте зелену кнопку **Code → Download ZIP** — вона завантажує весь цей репозиторій,
> а не розширення, і Chrome його не встановить. Потрібен саме файл `mpc.zip` за посиланням вище.

## Перше встановлення

1. Завантажте [mpc.zip](https://github.com/acidhacker/mpc-releases/releases/latest/download/mpc.zip).
2. Розпакуйте архів (подвійний клік) і перенесіть папку, що з'явилася, у постійне місце, яке не будете
   переносити або видаляти, наприклад `~/MPC` (macOS) чи `C:\MPC` (Windows). Усередині папки одразу має
   лежати файл `manifest.json`.
3. Відкрийте `chrome://extensions`, увімкніть **«Режим розробника»** (праворуч угорі).
4. Натисніть **«Завантажити розпаковане»** і виберіть цю папку.
5. Закріпіть іконку MPC на панелі Chrome.

## Оновлення

Коли вийде нова версія, у MPC з'явиться плашка **«Доступна версія …»**.
Натисніть **«Детальніше і оновити» → «Оновити»**.

Під час першого оновлення Chrome попросить:
- вказати папку MPC — ту, що в `chrome://extensions` у рядку «Завантажено з»;
- дозвіл — оберіть **«Дозволити під час кожного відвідування»**, тоді наступні оновлення пройдуть без питань.

Проєкти, ключі та історія зберігаються в Chrome, а не в папці, тож оновлення їх не зачіпає.

## Оновлення вручну (запасний шлях)

1. Завантажте [mpc.zip](https://github.com/acidhacker/mpc-releases/releases/latest/download/mpc.zip) — це завжди остання версія.
2. Розпакуйте його в ту саму папку MPC із заміною файлів.
3. У `chrome://extensions` натисніть ↻ у картці MPC.

## Безпека

Кожна версія підписана ключем автора (`latest.json.sig`). MPC встановлює оновлення, лише якщо
підпис збігається, тож підмінити архів неможливо.
